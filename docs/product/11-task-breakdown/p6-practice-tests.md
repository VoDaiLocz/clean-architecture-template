# P6 - Practice Test System

## Phase Goal

Provide TOEIC-like practice modes with scoring and repair plans.

| Task | Purpose | Key Pass Criteria | Commit |
| --- | --- | --- | --- |
| P6.1 Mini test runtime | Verify unit mastery | Result feeds mastery gate | `feat(p6.1): run TOEIC mini tests` |
| P6.2 Part test runtime | Test one TOEIC part | Official question counts enforced | `feat(p6.2): run TOEIC part tests` |
| P6.3 Listening section test | Combine Parts 1-4 | Section timing and breakdown supported | `feat(p6.3): run TOEIC listening tests` |
| P6.4 Reading section test | Combine Parts 5-7 | Section timing and breakdown supported | `feat(p6.4): run TOEIC reading tests` |
| P6.5 Full TOEIC test | Simulate LR exam | 200 questions, no hints, timed | `feat(p6.5): run full TOEIC LR tests` |
| P6.6 Timer/session state | Prevent unreliable testing | Resume/expire/submit rules defined | `feat(p6.6): manage TOEIC test sessions` |
| P6.7 Score breakdown | Explain performance | Part/tag/time breakdown returned | `feat(p6.7): calculate TOEIC score breakdown` |
| P6.8 Repair plan | Convert test into study plan | Weakness repair assignments created | `feat(p6.8): generate TOEIC test repair plans` |
