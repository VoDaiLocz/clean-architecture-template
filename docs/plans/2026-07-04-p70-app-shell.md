# Phase P70 & P71 Implementation Plan: Angular App Shell

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Remove legacy demo content and build the production Angular App Shell using "Ocean Classroom" Tailwind styling with a Floating Sidebar layout.

**Architecture:** Tailwind CSS for styling, Angular Router with lazy-loaded feature modules (Learner, Admin, Auth), and a Core Module for global layout components.

**Tech Stack:** Angular 21, Tailwind CSS v3/v4, Lucide Angular (icons).

---

### Task 1: Install Tailwind CSS & Lucide Icons

**Files:**
- Modify: `frontend/package.json`
- Create: `frontend/tailwind.config.js`
- Modify: `frontend/src/styles.css`

- [ ] **Step 1: Install Dependencies**
Run `npm --prefix frontend install -D tailwindcss postcss autoprefixer lucide-angular`
Run `npx --prefix frontend tailwindcss init`

- [ ] **Step 2: Configure Tailwind**
In `frontend/tailwind.config.js`:
```javascript
/** @type {import('tailwindcss').Config} */
module.exports = {
  content: [
    "./src/**/*.{html,ts}",
  ],
  theme: {
    extend: {
      colors: {
        'toeic-canvas': '#f4f9fc',
        'toeic-canvas-strong': '#eaf5fb',
        'toeic-surface': '#ffffff',
        'toeic-surface-soft': '#f8fbfd',
        'toeic-border': '#d9e7ef',
        'toeic-border-strong': '#b9d4e3',
        'toeic-primary': '#0787c8',
        'toeic-primary-hover': '#006fa8',
        'toeic-text': '#10222f',
        'toeic-text-muted': '#526879',
      },
      fontFamily: {
        sans: ['Geist', 'Inter', 'sans-serif'],
        serif: ['Source Serif 4', 'Georgia', 'serif'],
      }
    },
  },
  plugins: [],
}
```

- [ ] **Step 3: Update Global Styles**
In `frontend/src/styles.css`, prepend:
```css
@tailwind base;
@tailwind components;
@tailwind utilities;

body {
  @apply bg-toeic-canvas text-toeic-text font-sans antialiased;
}
```

- [ ] **Step 4: Commit**
`git commit -am "chore(p70): install and configure TailwindCSS and Ocean Classroom theme"`
